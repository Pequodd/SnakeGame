# NovaOS

Маленькая операционная система, написанная с нуля на C и ассемблере.
Внутри нет ни Linux, ни Windows: ядро само выводит текст на экран,
читает клавиатуру, считает время и запускает программы.

## Что умеет (версия 0.1)

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `clear` | очистить экран |
| `echo текст` | вывести текст |
| `calc (2+3)*4` | калькулятор |
| `time` | дата и время |
| `uptime` | сколько система работает |
| `mem` | объём памяти |
| `color 1..15` | цвет текста |
| `snake` | игра «Змейка» (стрелки или WASD, ESC — выход) |
| `reboot` / `halt` | перезагрузка / выключение |

## Как запустить на Windows

1. Установите эмулятор QEMU: https://qemu.weilnetz.de/w64/ (скачайте установщик и
   установите с настройками по умолчанию).
2. Скачайте эту папку `os` на свой компьютер (например, в `H:\NovaOS`).
3. Дважды щёлкните `run.bat`. Откроется окно с NovaOS.

Готовое ядро уже лежит в `build/nova.bin`, собирать ничего не нужно.

## Как собрать самому (Linux или WSL на Windows)

```bash
sudo apt install nasm gcc gcc-multilib make qemu-system-x86
make        # собрать build/nova.bin
make run    # запустить в QEMU
```

## Устройство

- `src/boot.asm` — точка входа: загрузчик передаёт управление сюда, мы ставим стек и вызываем ядро.
- `src/kernel.c` — ядро: экран, клавиатура, таймер, часы, командная строка и игры.
- `src/linker.ld` — где в памяти разместить ядро (с адреса 1 МБ).
